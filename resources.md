# Hacker Resources

Want to get a head start learning how to build on Solana? Check out these resources.

- [Solana Quickstart Guide](https://mlh.link/solana-quickstart) - Everything you need to start building on Solana.
- [Solana Quick Install Guide](https://mlh.link/solana-quick-install) - One command installs Rust, the Solana CLI, and Anchor on Mac, Linux, or Windows (WSL).
- [Solana DevNet Faucet](https://mlh.link/solana-faucet) - Fund your DevNet wallet so you're ready to deploy on day one.
- [Solana Developer Templates](https://mlh.link/solana-templates) - Production-ready starters for dApps, DeFi protocols, NFT marketplaces, and more.
- [Solana Agent Skills](https://mlh.link/solana-agent-skills) - Pre-built skills that let your AI agents work with Solana programs, tokens, and tooling.
- [Solana Courses on Blueshift](https://mlh.link/solana-tutorials): Dozens of courses to get comfortable with Solana fast.
- [Solana Developer Resource List](https://mlh.link/solana-resources) - Comprehensive list of Solana-related resources to get started with your hack.

Source: Hacker Resources section of the official event page, https://events.mlh.com/events/15200-solana-hackathon

## Game-specific resources

References for the Rivalry stack (see `prd.md`, section 12):

- [Phaser](https://phaser.io/) - JavaScript framework for browser-based 2D games; used for the Obstacle Rush mini-game so it runs inside the Rivalry web app.
- [Getting started with game development on Solana](https://solana.com/developers/guides/games) - Official Solana guide to building games with on-chain features.
- [Anchor Documentation](https://www.anchor-lang.com/docs) - Framework for the Solana program behind challenge commitments and prize escrow.
- [Solana 101 & Build with AI (MLH workshop video)](https://www.youtube.com/watch?v=WS53YSMhsvY) - shared by Utpal as extra prep material.
