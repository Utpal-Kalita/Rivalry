How a challenge runs

  1. 01Set the rules

    Difficulty, format, player cap and deadline. Under a minute.

  2. 02Send the link

    Every challenge has its own URL. Friends open it and join.

  3. 03Run the same course

    One seed builds the level, so the gaps, saws and coins match.

  4. 04Let the server rank it

    Your key presses are replayed. Only runs it reproduces count.

Scores the browser cannot fake

The game sends only its inputs. The server plays them back through the same physics, so edited timers and pasted scores fail the replay.

  • One-use nonce per attempt
  • Run time checked against real time
  • Deadline and membership checked
  • Each result signed for re-checking

Why it is fair

Nobody gets an easier level. The seed is locked before anyone plays, and the server decides who won.

Stakes settled on Solana devnet

  • Rules commitment. The creator's wallet signs a memo holding a SHA-256 hash of the seed and rules.

  • Prize escrow. A prize moves to the escrow wallet in the same transaction, confirmed on devnet.

  • Winner payout. When the challenge closes, the verified winner claims and escrow pays their wallet.

  • Seed proof. Each transaction links to the devnet explorer; the seed is published at close.
